**Random Quote Generator**

A simple and interactive Random Quote Generator built using HTML, CSS, and JavaScript. The application displays a randomly selected inspirational quote to motivate and encourage users.

🌟 About the Project

The Random Quote Generator provides users with a new quote whenever they generate a quote. It is designed with a clean and simple interface and demonstrates the use of JavaScript for dynamic content generation.

✨ Features

- 🎲 Generate a random quote
- 💡 Inspirational and motivational quotes
- 🔄 Generate a new quote with a button click
- 🎨 Clean and simple user interface
- ⚡ Fast and lightweight
- 📱 Easy to use
- 🌐 Runs directly in a web browser
- 💻 No external installation required

🚀 How to Run

1. Clone the repository:

git clone https://github.com/Sangeetha-ms5/Random-Quote-Generator.git

2. Open the project folder.
3. Open "index.html" in any modern web browser.
4. Click the Generate Quote button to display a new quote.

🔄 How It Works

Open Website
      ↓
Click Generate Quote
      ↓
JavaScript Selects a Random Quote
      ↓
Quote Displayed on Screen
      ↓
Click Again for a New Quote

🎯 Project Objective

The objective of this project is to create a simple interactive web application while practicing HTML, CSS, and JavaScript, especially JavaScript arrays, random selection, DOM manipulation, and event handling.
